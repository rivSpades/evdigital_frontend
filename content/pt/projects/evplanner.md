O EvPlanner junta no mesmo sítio o orçamento do mês, as dívidas a pagar e os objetivos de
poupança. É para quem quer perceber para onde vai o dinheiro sem depender de folhas de
cálculo.

O onboarding é guiado: a aplicação faz as perguntas pela ordem certa e só mostra números
quando já tem contexto para os explicar. Quem entra pela primeira vez percebe o que está
a ver.

Foi construído de ponta a ponta, do modelo de dados à interface. Está em produção, com
acesso público, e é o projeto que melhor mostra como trabalhamos: decidir o essencial
primeiro, entregar, e continuar a melhorar com uso real.
